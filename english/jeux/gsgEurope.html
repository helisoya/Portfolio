GSG - Europe (2022)

GSG - Europe is a 3D strategy game coded in Unity. It is an update to GSG 2 with the goal of publishing it to itch.io .

The player controls an european contry and must face their neighbors.

Language

C#

Unity

Game type

Strategy game

Dev time

2 months

Game features

The game is in first place an improvement of its predecessor, GSG 2.

- The loading times to launch the game have been reduced.

- The wars have been reworked. It is now necessary to make a peace treaty in order to annex a province.

- A shader effect has been added in order to better understand the difference between provinces and occupied provinces.

- A unit limit has been added to avoid an overflow of units among IAs.

- A system of national priorities has been added, allowing to obtain buffs making one's nation stronger.
