Mechs & Wizard (2023)

Mechs & Wizard is an action game created for the 'MechJam 2023' on Unity.

The player must destroy robots and advance in various levels.

Language

C#

Unity

Game type

Action

Dev time

2 weeks

Game features



- The Game Jam had about ten themes in which we had to choose one or two. I found it amusing to try to make a game merging all the themes. The result is a ridiculous/satirical story.

- The player must save the world by destroying the robots of a powerful wizard.

- Each level houses a dozen robots to destroy.

- The game contains cutscenes with audio for character voices.

- Destroying a robot gives credits, which can be used to improve its robot.

- There are several weapons, such as a missile launcher, a double gun, and a flame-thrower.
