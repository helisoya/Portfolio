Puzzle Truck (2024)

Puzzle Truck is a puzzle game created for GMTK 2024, and coded in Unity / C#.

You control a truck and have to solve puzzles with the crane on its roof. The final goal is to reconstruct a model with the parts that you recover at each end of the level.

Language

C#

Unity

Game type

Puzzle game

Dev time

4 days

Game features



- The game is divided into 6 levels, connected by a central hub. It is in this hub that you can see the model being built as you advance in the game.

- Before being able to access a level, you must solve a small puzzle serving as a tutorial for the mechanics that will appear in the level.

- Each level consists of the use of the crane to place cubes in special containers. This has the effect of activating, or deactivating, other components of the level, such as doors.

- There are several components in the game, such as conveyor belts, mobile platforms, and plates to shrink and enlarge the cubes. There are special containers for each size of cube.
