Harold's Quest 2 (2021)

Harold's Quest 2 is a visual novel coded in python. It improves the basics of its predecessors thanks to a flexible custom game engine.

The player must complete a quest in an open world that will lead them to make many encounters.

Language

Python

Game type

Visual Novel

Dev time

3 months

Game features

- The player can collect various hidden objects in the game, allowing them to unlock special endings.

- The game runs thanks to a game engine that allows you not to have to code to create an adventure. This means that the engine uses text files to link the different parts of the game.

- The engine also allows for animated characters to move their mouths when they speak, and for dubbing.

- The game also contains various mini-games that will appear throughout the adventure.
